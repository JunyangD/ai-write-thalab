# 05 改写后自审：模拟审稿清单

> **给谁看**：改写做完、复检达标之后的人。**降了 AI 率不等于改好了**——有些改法会把句子改坏、
> 改出逻辑缺口、或改出新的攻击面。本文件把学术审稿的标准压成一张**自查清单**，
> 让你在投稿前用审稿人的眼睛过一遍自己的改后稿。
>
> **来源**：集成 `academic-research-skills` 的评审智能体（`peer_reviewer_agent`、`revision_coach_agent`）
> 的五维评审框架，删繁就简为本技能可执行的清单。**本清单仅供自审，不得当作真实期刊审稿意见对外使用。**

---

## 一、五维评审框架（改写后逐维过）

| 维度 | 要回答的问题 | 改写时最容易被破坏的点 |
|---|---|---|
| **原创性 Originality** | 主张的贡献相对相关文献站得住吗？ | 删模板词时把「贡献陈述」一起删没了 |
| **方法严谨 Methodological Rigor** | 设计、执行、分析、报告能支撑结论吗？ | 「轻改」方法段时误删步骤或改了叙述顺序导致不可复现 |
| **证据充分 Evidence Sufficiency** | 每个实质主张都有对得上类型的证据吗？ | 把「判断句换数据陈述」做成「删判断但不补数」 |
| **论证连贯 Argument Coherence** | 问题→方法→发现→含义这条链可追溯吗？ | 拆句 / 换主语时打断了因果链 |
| **写作质量 Writing Quality** | 措辞和组织足以让人解释与核对吗？ | 长短句交替做过头，句子碎裂 |

> 判定用**分档**而非打分：`EXCEEDS / MEETS / PARTLY_MEETS / DOES_NOT_MEET / NOT_ASSESSED`。
> 不要给自己算总分，也不要因为某一维很好就放过另一维的硬伤。

## 二、自审清单（逐条打勾）

### A. 数据与引用保全（红线，最先查）
- [ ] 逐项对照改前 / 改后：数字、年份、百分比、图表编号**零改动**。
- [ ] PMID / DOI **零改动**；每条引用为真实存在且指向正确论文（见 `09_citation_integrity.md`）。
- [ ] 正文 `（pmid：` 次数与参考文献条数一致；红色 `C00000`；句号在括号外。
- [ ] 专业术语（地中海贫血、铁过载、ferroptosis、ACSL4、GPX4、hepcidin、TDT、NTBI 等）**未被替换**。

### B. AI 味是否真的下来了
- [ ] 全文 AIGC 疑似率（模型通路）**< 5%**；`detox_pipeline.py` 判定为「达标」。
- [ ] 模板词（`02` A/B 组）**零残留**；连接词每段 ≤1 个。
- [ ] 有一份**阳性 / 阴性对照**（`calibrate.py`）证明检测器在工作。
- [ ] 段内句长有明显起伏（不长不短全一个样）。

### C. 改写有没有把句子改坏
- [ ] 每一处「判断句 → 数据陈述」都**补上了具体数或限定语**，不是删了判断留个空。
- [ ] 拆句之后，被拆开的句子之间有明确的逻辑关系（因果 / 转折 / 递进 / 对比），不是硬断。
- [ ] 换主语之后，主语与谓语的搭配仍然成立（没有出现「数据做了实验」这类错配）。
- [ ] 没有引入新的错别字、重复词、半截句。

### D. 反防御（别改出新攻击面）
- [ ] 没有新增「本研究不宣称…」「须特别声明…」这类自证句。
- [ ] 方法学限制 / 样本量边界**保留**了，只删了重复与预防假想误解。
- [ ] 结论段没有突然的自我否定。
- [ ] 摘要前五句里，问题和贡献都出来了。

### E. 论证连贯
- [ ] 问题 → 方法 → 发现 → 含义这条链完整可追溯。
- [ ] 每个实质主张都有对得上类型的证据（不是「证据不足」被改成了「没有证据」）。
- [ ] 跨节引用（「见 §2.2」）指向的地方确实说了这件事。

## 三、改写后的再评审协议（最多两轮）

模仿真实的返修循环，但**不吹哨子把整篇推倒**：

```
第 1 轮：按上面 A–E 全过一遍 → 列出所有问题，分 Critical / Major / Minor
         → 修掉 Critical 与 Major
第 2 轮：只复看被改过的段 + 改动引入的新问题
         → 若 Critical / Major 都已闭环，通过；否则如实记录未闭环项
```

**严重度定义**（用于排序，不用来算分）：
- **Critical**（挡发表）：方法论根本缺陷、主结论无证据支撑、严重抄袭嫌疑、引用伪造。
- **Major**（影响质量）：某节论证不足、缺重要反证、数据呈现不清。
- **Minor**（小问题）：过渡生硬、个别段落过长、几处引用格式错误。

---

## 四、收敛不了的诚实出口

若两轮仍未闭环，**不要硬说通过**。三条出口，任选其一，并如实记录：

- **出口 A**：接受现状，把所有未解决问题写进「已知局限（Acknowledged Limitations）」段，继续。
- **出口 B**：扩大返修，回到相应环节（补证据 / 重构论证 / 重定位贡献）。
- **出口 C**：终止，保存现有稿件与全部评审记录，交作者自行决定。

---

## 五、和「降 AI 率」的关系（一句话）

降 AI 率解决的是「**像不像机器写的**」；本清单解决的是「**改完之后还是不是一篇好论文**」。
两者必须都过——**只降分不改好，等于用机器的方式躲机器的检测。**
