## 2. 覆盖范围与边界（诚实标注）

- **中文语料 = 单一拟投期刊**（《广西医科大学学报》）近 4 期，**非全网中文论文**；
  好处是"拟投期刊文风"最精准。
- **英文语料 = PubMed「thalassemia」最新发布前 20 篇**，含综述 / 指南 / 病例报告 / 原创研究多类型。
- **未取得**：中文非本刊论文、英文全文正文（仅摘要）。
- 若后续需要"多种中文期刊"，需扩源（CNKI），届时语料代表性会变，文风规则需重算。

## 3. 可复用的真实例句（按用途分类）

> 以下例句均来自上述语料，可作**正面模板**直接模仿句式（但不要照抄内容）。
> 带 `[n]` 的是中文篇号；`PMID:xxx` 是英文条目。

### 3.1 转折 / 总结
- （[1] 转折）"然而，天然产物直接用于生物成像和精准诊疗，面临着以下几个临床真实痛点问题…"
- （[3] 总结）"综上所述，本研究发现并验证了AmLEVs可通过减轻高糖环境下的氧化应激损伤…"

### 3.2 背景 / 动机
- （[1]）"近年来，研究者发现诸多天然产物自身便具备内在的AIE特性…"
- （[3]）"然而，目前AmLEVs活性成分及其在糖尿病创面修复中的作用尚未报道。基于此，本研究拟探讨…"

### 3.3 结果句（必带数字的样板）
- （[50]）"在100例Hb F增高的病例中检出25例有KLF1基因突变。Hb分析显示25例的Hb F水平为4.9%～75.9%，血红蛋白A2（Hb A2）水平为1.2%～6.3%。"
- （[4]）"…神经功能缺损评分显著降低"

### 3.4 判断 / 提示句
- （[3]）"这提示AmLEVs能够有效清除多种类型的自由基，具有较强的抗氧化能力。"

### 3.5 局限 / 展望（讨论末段）
- （[27]）"本研究存在一定的局限性：采用便利抽样法，样本代表性可能不足…"
- （[4]）"未来可围绕SI的上游调控机制、性别差异、长期效应及临床转化开展更深入的研究…"

### 3.6 英文样句
- （PMID:42865314, RESULTS）"A total of 2,878 publications were identified, with annual output peaking in 2021 (333 papers)."
- （PMID:42865314, METHODS）"Articles on thalassemia were retrieved from the Web of Science Core Collection."
- （PMID:42846697）"Cord blood-based neonatal genetic screening … was conducted."

## 5. 这些语料怎么变成了规则

| 语料观察 | 转成的规则 | 落在哪 |
|---|---|---|
| 转折"然而 78 : 但是 14" | 中文转折优用"然而" | `01` §A2、`02` §1 对照表 |
| "总而言之 0 次" | 不用"总而言之" | `02` §1 A 组 |
| 结果句必带 ±SD / P 值 / 图号 | 结果段必须落数字 | `01` §A6-2、`05` 自审 B |
| 句长极不均匀（20–130 字） | 句长突变是核心手法 | `01` §A6-8、`03` 手法 6 |
| 讨论末段 32/63 篇含"局限" | 保留方法学限制句 | `04` §二、`05` 自审 D |
| 英文 "In conclusion," 0 次 | 用 "These findings suggest…" | `01` §B2、`02` §2 |
| 首见术语给中英对照 | 术语首现给对照 | `01` §A6-7 |

> **可脚本化的部分**已经写进 `scripts/fingerprint.py` 的 7 个维度（见 `01` §D）。
> 不可脚本化的（局限性段、术语分型、第一人称越界、结果句带数）落在 `05_reviewer_simulation.md` 的人工清单。
