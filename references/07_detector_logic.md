# 07 查重与降 AI 逻辑：原理、为什么同义词替换无效、诚信边界

> **给谁看**：想知道「到底在跟什么机制较劲」的人，以及需要向导师 / 编辑解释「我们怎么降低 AI 率」的人。
> **可信度纪律**：下文凡**未经我方亲验**的原理与阈值，一律标注「**据公开资料归纳，未经官方确认**」。
> 维普 / 万方 / 知网的检测器均为**闭源商业系统**，权重与阈值为厂商私有，**任何人给出的"精确数值"都只能当参考**。
> 我方亲验的部分见 §6。

---

## 1. 先分清两套检测：查重 ≠ AIGC

| 维度 | 查重（文字复制比 / 相似度） | AIGC 检测（生成痕迹） |
|---|---|---|
| 回答的问题 | 这段文字**是否抄了已有文献** | 这段文字**是否像 AI 写的** |
| 比对对象 | 已有文本（期刊库 / 学位论文 / 网络 / 图书） | **语言统计特征**（无需比对库） |
| 核心度量 | 连续字符 / 句子 / 段落级相似 | 困惑度、突发性、模板化等统计指纹 |
| 降低手段 | 改写、规范引用、去未标注引用 | **改变句法结构**（不是换词） |
| 关键差异 | 抄了才高 | **自己独立写的也可能被判"像 AI"** |

**一句话**：查重防的是"抄别人的"，AIGC 防的是"像机器写的"。两者降低手法部分重叠但**不等价**——
同义词替换对前者略有用、对后者**基本无效**（§4）。

## 2. 三家查重原理差异（**据公开资料归纳，未经官方确认**）

| | 知网 | 万方 | 维普 |
|---|---|---|---|
| 库覆盖 | 最全（含图书 / 学位 / 年鉴） | 中（期刊 / 学位 / 会议 / 网络） | 中偏中文期刊 |
| 判定粒度（坊间口径） | 连续字串为主 | 句子级相似为主 | 字面 + 语义特征 |
| 同稿相对得分 | 通常最高 | 通常较低 | 居中 |
| 特色 | 去除本人已发表 | — | 中文期刊覆盖 |

- **知网**：库最厚，判定偏好"连续字串"；"去除本人已发表文献"对自引友好。「连续 13 字符」口径**未经官方确认**。
- **万方**：更强调**句子层面的语义与字面相似**，是按句聚合。
- **维普**：结合字面比对 + 一定语义特征，对**段落重组型**改写比纯字面系统更敏感。

> **实际使用建议**：投稿前以目标期刊 / 学校指定的那一家为准；不要用 A 家的低分推断 B 家也低。

## 3. 三家 AIGC 检测原理（公开口径归纳）

> **重要**：三家 AIGC 均为**闭源**，基于私有语料与模型权重，**其"百分比数值"无法被第三方复现**。

### 3.1 维普 AIGC
- **底层**：据公开资料称基于 **Transformer 类模型**做生成文本判别。
- **判据**（公开口径）：
  - **困惑度（perplexity）**——AI 文本"更可预测"，困惑度偏低；
  - **突发性（burstiness）**——人类写作句长起伏大，AI 句长偏均匀；
  - **句式规整度 / 模板化**——固定开头结尾、对称结构多；
  - **对抗样本识别**——识别"为躲检测而故意打乱"的文本。
- **阈值口径**（据公开资料归纳，未经官方确认）：**≥25% 标红**；核心期刊常要求 **<10%**。
- **特点**：即使文本是**独立原创**，只要句式太规整，也可能被标"疑似 AI"。

### 3.2 知网 AIGC
- 公开资料称基于大模型做生成内容识别，与查重系统分开呈现。
- 特点：对"经典结构 + 高频连接词"的整段更敏感；对**逐句改写但保留模板骨架**的文本仍可能命中。
- 阈值：未公开统一标准，不同学校 / 期刊自行划线。

### 3.3 万方 AIGC
- 公开资料称结合统计特征与深度学习模型。公开信息少于前两家；**不建议仅凭万方结果推断维普 / 知网结果**。

### 3.4 必须知道：开源检测器 ≠ 官方检测器
用开源中文 RoBERTa 做阳性 / 阴性对照（我方亲验，见 §6）：
- 阳性①（塞满"随着…值得注意的是…综上所述"）→ **99.99%**（对**明显模板文**灵敏）；
- 阳性②③（**含蓄的** AI 文）→ 仅 **0.51% / 0.19%**（**模型偏保守、会漏检**）；
- 阴性（真人文本）→ 全 0。

**结论**：开源检测器**低分 ≠ 官方低分**，两者不能互推。**定稿后必须跑目标系统的官方检测。**

> **补充（独立验证发现）**：英文开源检测器的区分度**不稳**——同一「formulaic」风格，
> 主题为 artificial intelligence 的段落得 98.67%，而主题为 ferroptosis 的只有 9.28%；
> 疑似把「AI 话题词汇」当成了强特征。因此**不要单凭英文模型读数判定英文稿件达标**，
> 定位问题请以规则指纹的逐维分解为主。

## 4. 为什么浅层同义词替换无效

同义词替换只改变**词形**，不改变**句法结构**，而 AIGC 检测吃的正是**句法 / 统计结构**：

1. **困惑度不降反升有限**：把"表明"换成"显示"、"重要"换成"关键"，整句可预测性几乎不变。
2. **突发性（句长分布）完全不变**：换词不改句长，句长方差**原封不动**。
3. **模板骨架保留**："综上所述，X 具有重要价值…"换成"总而言之，X 具备关键意义…"——骨架、节奏、连接词位置一模一样。
4. **对查重也有限**：连续字串判定看的是连续字符重合，逐词替换若不同步调整语序，连续重合片段仍可能残留。
5. **反而可能踩"对抗样本识别"**：低质、机械的同义替换，在含对抗样本识别的检测器下，**可能被识别为"为躲检测而改写"**，得不偿失。

> 一句话：**同义词替换是"换皮"，检测器看的是"骨架"。**

## 5. 什么样的改写才真有效（结构层面）

有效改写的共同点是**改变统计结构**。四类手法（与 `03_rewrite_playbook.md` 对应）：

| 手法 | 打掉的指标 |
|---|---|
| **5.1 句长突变**：长短句刻意交替，避免整段集中在 25–35 字的"平台期" | 突发性 / `sent_cv` |
| **5.2 主语轮换**：每段至少两种主语（本研究 / 数据 / 结果 / 文献 / 该机制） | 句首重复 / `start_rep` |
| **5.3 信息重组**：拆句、并句、调换因果/对比/递进的呈现顺序；主动↔被动转换 | 句式规整度 |
| **5.4 删模板词、去金句**：直接移除高频指纹 | 模板密度 / 连接词密度 |

> **有效性排序**（经验判断）：删模板词/金句 ≈ 句长突变 > 主语轮换 ≈ 信息重组 >> 同义词替换（基本无效）。

**语料佐证**（T1，实测）：真人中文摘要单句中位 68 字、英文 19.5 词，且一篇里**既有 20 字短句也有 130 字长句**；
AI 文本句长分布过于均匀 ⇒ 句长方差是区分真人与 AI 的可测维度之一。

## 6. 我方亲验记录（可复现）

1. **维普闭源**：判据公开（困惑度 / 突发性 / 句式规整度 / 模板化 / 对抗样本识别），阈值 ≥25% 标红；**数值无法复制**。
2. **两层自建检测**：① 规则型指纹检测器（改前 31.0 → 改后 19.2/100）；② 开源模型 `Hello-SimpleAI/chatgpt-detector-roberta-chinese` → v4 全文 0.0045%、0 段 ≥50%。
3. **阳性 / 阴性对照必做**（否则"0%"不可信）：阳性① 99.99% / 阳性②③ 0.51%、0.19% / 阴性全 0。
4. **结论原话**：本文在开源检测器下远低于 5%，**但不能据此保证维普结果**；建议定稿后跑维普官方、被标红段落定向改写。

> **对照原则**：任何"降到了 X%"的结论，**必须同时给阳性对照**——只有阳性对照被正确召唤出来，
> 才能证明检测器在"工作"而非"失灵"。

## 7. 学术诚信边界（必须守）

1. **AI 的角色 = 文字组织，不是内容生成。** 研究问题、方法、数据解释、论点归属由研究者负责（"AI 是副驾驶，不是飞行员"）。
2. **改写不得改变事实**：数据、年份、百分比、PMID/DOI、作者、机构、检索式、图表编号、结论方向一律不动。
3. **不得新增未提供的文献与结论**；**禁止虚构引用**，PMID 须 esummary 逐条回读核验，核验不通过一律剔除。
4. **如实披露优于掩盖**：有期刊要求"AI 使用声明"的，如实申报"AI 仅用于语言组织 / 格式整理"；**为躲检测而刻意打乱文本**（对抗样本识别正是针对这类行为）**风险高于收益**。
5. **"降 AI 率"的目标是"让真人写的东西不被误判"，不是"让抄来的东西蒙混过关"。** 若内容本身来自未标注的他人文本，任何"降 AI"手法都不改变其抄袭性质——那是查重与学术不端问题，不是文风问题。
6. **投稿前跑官方检测**：本套自建 / 开源检测仅作**投稿前预筛**，结论以目标期刊 / 学校指定系统为准。

## 8. 可执行接口小结

- **输入**：待检文本（中 / 英）。
- **三步预筛**（本地、可复现）：
  1. 规则型指纹：句长 CV、模板词密度、连接词密度、句首重复率、逗号占比、TTR → 综合分；
  2. 模板词表命中（`02_template_wordlist.md`）→ 命中清单；
  3. 结构特征（句长分布、每段主语数）→ 高风险段列表。
- **阳性对照自检**：`calibrate.py` 内置"明知是 AI 模板文"的样例，应被稳定判为高风险；否则检测器不可用。
- **输出**：高风险句列表 + 逐句人工修改建议（拆句 / 换主语 / 加限定 / 删模板词）+ 数据保全核对表。
- **红线**：只给建议，**不自动改数据、不自动新增文献**；改写后须再跑一次数据保全核对。
